# Surface brief — Home (index route)

## Scope
Primary marketing surface (mode: Persuade). Must earn contact from enterprise prospects, international clients/partners, talent, and press; preserve products (Boowa, EYD, Aura), solutions, industries, case studies, careers, contact, partner routes and truthful copy.

## Direction contract

**THESIS** — PSM is a ledger, not a brochure: precision documentation of problem-solving, where every claim is an auditable entry. It refuses the category default of gradient/glass startup polish and of soft editorial serif warmth alike.

**OWN-WORLD** — Light canvas carries the current palette (ink/void text on `--canvas #f4f5f8`, electric-iris `--accent-azure` as the only active action accent, verdant green reserved for certified/verified marks). Materials are hairline rules, thin rules that cross the page like ledger registers, tabular figures, small tracked-caps labels, stamped mono codes (e.g. `PSM-001`), and ruled column headers. No blobs, no glass, no emoji.

**STORY** — A first-time visitor sees a precise, quiet technical firm, understands it starts from problems, and reaches Contact knowing the offer is documented and certifiable.

**FIRST VIEWPORT** — A ruled register: top hairline rulebar carries issue code + date; the layout is a measured 12-column grid with thin vertical rules; headline set in PP Neue Montreal (trimmed caps + tabular title), a single electric-iris primary action (Contact), and a right-column "problem → solution" register entry with tabular figures and a stamped status. Signature interaction: the ledger spine — vertical hairline rules pan/trace with scroll to reveal entry rows.

**FORM** — Ledger/register form (grounded candidate #7, seed key d91f0f8f), code-led build.

**FINISH** — unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
